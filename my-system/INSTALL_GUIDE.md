# 🚀 Xeyal-System Installation Guide | Kurulum Kılavuzu | Руководство по установке

![Installation Guide](installation_guide.png)

---

## 🇹🇷 Türkçe (Turkish)

### 1. Dosyaları Çıkarın

İndirdiğiniz ZIP dosyasındaki tüm klasörleri bir yere çıkarın (Örn: Masaüstü veya Belgerim).

### 2. Kurulumu Başlatın

Klasör içindeki `install.ps1` dosyasına sağ tıklayın ve **"Run with PowerShell" (PowerShell ile çalıştır)** seçeneğini seçin.

> [!IMPORTANT]
> Sistem dosyalarını kopyalamak ve kısayol oluşturmak için izne ihtiyacımız var. Güvenlik uyarısı çıkarsa "Evet" veya "Tümüne Evet" deyin.

### 3. Sistemi Hazırla

Kurulum tamamlandığında masaüstünde **Xeyal-System** logolu bir kısayol oluşacaktır.

---

## 🇬🇧 English

### 1. Extract Files

Extract all the content of the downloaded ZIP file to a folder (e.g., Desktop or Documents).

### 2. Run the Installer

Right-click on the `install.ps1` file inside the folder and select **"Run with PowerShell"**.

> [!IMPORTANT]
> We need permissions to copy system files and create shortcuts. If a security prompt appears, please select "Yes" or "Yes to All".

### 3. Launch System

Once complete, a **Xeyal-System** shortcut will appear on your desktop.

---

## 🇷🇺 Русский (Russian)

### 1. Извлеките файлы

Распакуйте содержимое ZIP-архива в любую папку (например, на Рабочий стол).

### 2. Запустите установку

Нажмите правой кнопкой мыши на файл `install.ps1` и выберите **"Выполнить в PowerShell"**.

> [!IMPORTANT]
> Нам нужны разрешения для копирования системных файлов и создания ярлыков. Если появится запрос безопасности, выберите «Да» или «Да для всех».

### 3. Готово

После завершения на рабочем столе появится ярлык **Xeyal-System**.
