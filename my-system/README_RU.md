# 🚀 Xeyal-System: Ваш Автономный Помощник Разработчика

## ⚡ Одна Команда. Полный Контроль

```bash
npx xeyal-system dev
```

### Хватит тратить время на исправление ошибок, управление портами и запуск одних и тех же команд каждый день. Позвольте Xeyal-System взять всю "рутину" на себя

## 🔥 Что Происходит При Запуске?

1. 🔍 **Определяет Фреймворк**: Мгновенно распознает Next.js, Vite, Express или любой другой стек.
2. 📦 **Исправляет Зависимости**: Нет `node_modules`? Система установит их сама.
3. 🔓 **Освобождает Путь**: Находит конфликты портов и **с вашего одобрения** безопасно их устраняет.
4. 🚀 **Запускает Проект**: Синхронно запускает сервер разработки и инструменты мониторинга.
5. 🧠 **Диагностический Щит**: Следит за логами в реальном времени. Если что-то упадет — предложит решение быстрее, чем вы успеете заметить.
6. 🧬 **AI Swarm & Skills Hub**: Запуск специализированных автономных агентов (OpenClaw, Coder-Pro) для решения сложных задач.

## 🧰 Основные Команды

- **dev** → Автоматический запуск всего (Магическая кнопка).
- **fix** → Мгновенное исправление проблем окружения.
- **explain** → Объяснение сложных ошибок простыми словами.
- **doctor** → Глубокая диагностика железа и ПО.
- **skills** → Управление специализированными ИИ-агентами.
- **cockpit** → Запуск тактической панели управления (TUI).
